# Prospective Hydraulic certificate development prototype

Saved before new validation outcomes or timings, 2026-10-02. No classifier is fitted. The frozen seed-17 full HGB and existing predictor-fit-only scaler are reused. Only the 907 predictor-fit and 223 internal-validation rows are consumed; no gate partitions, old test, or HAR outcomes are used.

Initial input is empty. The order is fixed by the sum of positive fitted-tree split gains per physical block divided by the prior 40-fitting-case, five-repeat median processing cost. Only blocks with an actual fitted split are used. Gain is a training-model ordering heuristic, not causal feature importance. The order is saved before validation reference predictions. Delta is fixed at 0, .01, .025, .05, .1; every value is reported.

For numeric splits, an observed value chooses its true child; an unobserved value unions both children. Static subtree leaf-value bounds are maintained by compiled updates of affected split nodes and ancestors. Leaf values are already shrunk. Score sums and softmax intervals are expanded conservatively in float64. A dual lower value of bounded-simplex distance yields a conservative all-label half-Brier excess certificate. The final bound is evaluated at the actual emitted probability. Exact reachable-score collapse returns the native full-equivalent probability with analytic zero excess. All model-used blocks likewise return the exact full prediction. Numerical checks support implementation fidelity and are not formal all-input floating-point proof.

Primary complete per-episode time starts with resident raw windows and includes allocations, actually executed statistics/FFT/scaling, bound updates, certificate, control, and output construction. It excludes acquisition, transport, disk I/O, training, JIT compilation, and timer-outside correctness reference/label evaluation. No artificial delay. Primary timing has no component instrumentation. Optimized native full processing computes only actual model-used blocks. A compiled exact full tree traversal uses the same feature operators and is a second full comparison. Partial-processing savings are assessed against the faster full implementation.

The first 24 validation rows in fixed original order are a correctness and coarse-cost check, followed by all 223 development rows. Three timing repetitions use fixed-seed randomized method order, no method selection on outcomes. Controls are tight minimax, coordinate-relaxed minimax using the same simplex output projection, tight certificate evaluated at normalized interval midpoint, native full, and compiled exact full. All tolerances and controls are retained. Per-case risk, full-relative excess, maximum label-wise violation, block count, fallback, complete mean/median/P95/P99, and diagnostic separate component costs are reported. Development results cannot retrospectively pass the old pilot and cannot be described as independent confirmation.

Conservative arithmetic allowances: score sums use an eightfold gamma-n absolute-sum allowance plus 1e-12; each softmax endpoint expands by 2e-13; dual lower values subtract 2e-12; final certificate adds 2e-11 and rounds upward. These are conservative engineering guards with IEEE float64/basic-operation and elementary-exponential accuracy assumptions, not a formally verified machine-arithmetic enclosure. Infeasible interval-simplex bounds safely widen to [0,1].
